# FMCG Inventory & Distribution Portal 📦

> **Fast-Moving Consumer Goods (FMCG) distribution and inventory management portal built with React and Express.**

[![React](https://img.shields.io/badge/React-UI-61DAFB?style=flat&logo=react)](https://react.dev)
[![Express](https://img.shields.io/badge/Express-REST%20API-black?style=flat&logo=express)](https://expressjs.com)

---

## 📌 Overview
Enterprise portal for FMCG wholesalers and distributors to manage batch tracking, warehouse stock levels, and retailer dispatches.

---

## 🚀 Setup
```bash
# Backend
cd backend && npm install && npm start

# Frontend
cd frontend && npm install && npm start
```
